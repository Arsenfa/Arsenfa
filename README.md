## Featured Projects

### KasirKu
**Modern Android POS System**

Production-grade Point of Sale application for retail businesses. Built with Jetpack Compose and Material 3, featuring multi-cashier support, real-time reporting, thermal printer integration, and a comprehensive admin panel.

**Stack:** Kotlin, Jetpack Compose, Room DB, MVVM, Material 3

**Key Features:**
- Multi-cashier management with PIN authentication
- Real-time sales analytics and profit tracking
- Barcode scanning and inventory management
- Bluetooth thermal printer support
- Dark mode with automatic theme switching
- Data export to CSV and JSON for backup

### NoteAi
**AI-Powered Note-Taking Application**

Intelligent Android note app leveraging Gemini AI for advanced features including OCR, summarization, and conversational AI assistance.

**Stack:** Kotlin, Jetpack Compose, Firebase Auth, Gemini API, MVVM

**Key Features:**
